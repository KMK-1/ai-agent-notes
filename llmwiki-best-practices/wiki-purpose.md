# Wiki Purpose

## Mission

Turn heterogeneous source material into a durable, traceable, low-duplication knowledge base that becomes more useful as evidence accumulates.

## Optimize for

1. Correctness and provenance
2. Reuse across future questions/tasks
3. Low duplication and stable canonical pages
4. Clear handling of uncertainty and disagreement
5. Fast retrieval for both humans and agents
6. Incremental maintenance rather than full rebuilds

## Do not optimize for

- Maximizing the number of pages
- Rewriting every source into prose
- Hiding uncertainty for a cleaner narrative
- Creating domain taxonomy in the core framework
- Re-deriving stable knowledge on every query

## Human / agent ownership

| Layer | Default owner | Rule |
|---|---|---|
| Sources | Human/system | Curated evidence; normally immutable |
| Wiki | Agent | Maintained derived knowledge |
| Schema/config | Human + agent | Co-evolves deliberately |
| Generated indexes/health reports | Agent/tooling | Rebuildable derived state |
